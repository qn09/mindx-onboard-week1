## Usage in Markdown

Images are referenced using relative paths:
```markdown
![Description](images/image-name.png)
```

## Adding New Images

1. Save screenshots or diagrams to this folder
2. Use descriptive filenames (e.g., `azure-deployment-diagram.png`)
3. Reference them in markdown files using relative paths
4. Add descriptions to this README
